# 기상안내전광판 — GitHub Pages 호스팅

384 × 432 · Colorlight A200 · 기상청 단기예보 API

```
[A200 내장 브라우저]
   ↓ ① GitHub Pages 에서 화면 파일 받기
   ↓ ② 기상청 API 직접 호출
[LED 전광판]
```

**서버도, PC도, 라즈베리파이도 필요 없습니다.** 수집을 서버에서 하지 않고 A200 의
브라우저가 직접 기상청을 호출합니다. GitHub Pages 는 파일만 놓아두는 역할입니다.

---

## 파일 구성

| 파일 | 역할 | 수정 빈도 |
|---|---|---|
| `index.html` | 화면 전체 (아이콘 12장 내장, 100KB) | 거의 없음 |
| `config.json` | 지역·좌표·색상·인증키 | 설정 바꿀 때 |
| `robots.txt` | 검색 엔진 색인 차단 | 없음 |
| `.nojekyll` | GitHub Pages 빌드 우회 | 없음 |

`index.html` 안에도 기본 설정이 들어 있고, `config.json` 이 있으면 그 값이 우선합니다.
그래서 **설정을 바꿀 때 100KB HTML 을 건드릴 필요가 없습니다.**
`config.json` 에는 바꿀 항목만 써도 되고, 안 쓴 항목은 기본값이 유지됩니다.

---

## ⚠️ 먼저 알아야 할 것 — 인증키가 공개됩니다

브라우저가 API 를 직접 호출하는 구조라 인증키가 파일에 평문으로 들어갑니다.
정적 호스팅에 올리면 **URL 을 아는 사람은 누구나 키를 볼 수 있습니다.**

| 항목 | 내용 |
|---|---|
| 금전 피해 | 없음. 기상청 API 는 무료이고 과금이 없습니다 |
| 실제 위험 | 타인이 키를 쓰면 일일 트래픽 한도가 소진되어 전광판이 멈춥니다 |
| 대응 | 공공데이터포털에서 키 재발급 (즉시 가능) |

줄이는 방법:

- **저장소·파일 이름을 추측하기 어렵게** 하세요. `weather-board` 보다
  `disp-7f3a` 같은 이름이 낫습니다. URL 이 알려지지 않으면 실질적으로 안전합니다
- `robots.txt` 로 검색 노출을 막았습니다 (포함되어 있음)
- 저장소를 어디에도 링크하지 마세요
- 트래픽이 비정상으로 늘면 공공데이터포털에서 확인 후 키를 재발급하세요

이게 부담되면 **USB·로컬 파일 방식**을 쓰세요. `index.html` 하나만 A200 에 넣으면
되고 키가 외부에 노출되지 않습니다.

## 1. 설정 먼저 (PC 에서)

`index.html` 을 PC 에 두고 브라우저로 엽니다. 주소 끝에 `?setup=1` 을 붙이세요.

```
file:///D:/board/index.html?setup=1
```

1. 기상청 **일반 인증키(Decoding)** 붙여넣기
2. `API 3종 테스트` — 3개 모두 성공 확인
3. 지역·좌표·색상·표시항목 조정 (미리보기로 즉시 확인)
4. **`config.json 복사 (호스팅용)`** 클릭

## 2. 저장소 만들기

1. GitHub 에서 새 저장소 생성 — **Public** (무료 계정은 Public 만 Pages 가능)
   - 이름은 추측하기 어렵게
2. 이 폴더의 파일 4개를 업로드
3. `config.json` 을 열어 **1번에서 복사한 내용으로 전체 교체** → Commit

## 3. Pages 켜기

저장소 → **Settings** → **Pages**

| 항목 | 값 |
|---|---|
| Source | Deploy from a branch |
| Branch | `main` / `/ (root)` |

1~2분 뒤 주소가 발급됩니다.

```
https://<사용자>.github.io/<저장소>/
```

브라우저로 먼저 열어 화면이 정상인지 확인하세요.

## 4. A200 연결

PlayerMaster → 프로그램 편집 → **웹페이지 창** 추가 (384 × 432 전체화면) → URL 입력

```
https://<사용자>.github.io/<저장소>/
```

---

## 설정 바꾸기

1. PC 에서 `index.html?setup=1` 열기 (로컬 파일 그대로 써도 됩니다)
2. 값 조정 후 **`config.json 복사`**
3. GitHub 에서 `config.json` 열기 → 연필 아이콘 → 전체 교체 → Commit
4. 1~2분 뒤 반영. A200 은 갱신 주기마다 `config.json` 을 다시 읽습니다

`index.html` 은 손대지 않습니다.

---

## 알아둘 점

**A200 이 인터넷에 연결돼 있어야 합니다.** 화면 파일을 받는 것도, 기상청 API 를
호출하는 것도 인터넷이 필요합니다. 다만 API 호출 때문에 어차피 필요한 조건이라
호스팅이 새 의존성을 만드는 것은 아닙니다.

**갱신 주기는 10분이 기본입니다.** API 3개를 쓰니 하루 432회입니다. 더 짧게 하면
공공데이터포털 일일 트래픽 한도에 가까워집니다. 기상청 실황은 매시 갱신이라
10분이면 충분합니다.

**A200 시계가 틀어져도 동작합니다.** 발표시각 계산이 어긋나면 이전 발표분으로
물러나며 재시도합니다 (실황 6회, 초단기예보 4회, 단기예보 3회).

**주간예보는 4일입니다.** 단기예보가 글피까지라 그렇습니다.

**시간별 곡선은 인라인 SVG 입니다.** A200 내장 브라우저가 SVG 를 못 그리면 그
부분만 비어 보일 수 있습니다. 나머지는 CSS 와 PNG 라 안전합니다.

**GitHub Pages 캐시.** 커밋 후 반영까지 1~2분 걸립니다. `config.json` 요청에
캐시 무효화 파라미터를 붙여두었으므로 A200 이 옛 설정을 계속 쓰는 일은 없습니다.

## 다른 방식으로 되돌리려면

`config.json` 의 `displayMode` 만 바꾸면 됩니다.

| 값 | 용도 |
|---|---|
| `fit` | A200 웹페이지 창 (현재 방식) |
| `hdmi` | 라즈베리파이 HDMI 를 A200 에 직결하는 방식. 좌상단 1:1 고정 |
